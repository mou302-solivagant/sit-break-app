# 起身休息提醒 App

依「久坐提醒App_架構規劃.md」實作的Electron桌面App原型。每隔一段時間（預設30分鐘）提醒起身，可暫時鎖住螢幕1-10分鐘，鎖定期間輪播健康知識卡片（內建四篇久坐醫學實證懶人包，可自行新增圖片/文字）。

## 如何在自己電腦上執行（Mac / Windows 皆可）

1. 安裝 [Node.js](https://nodejs.org/)（建議 LTS 版本）
2. 在終端機切到這個資料夾，安裝套件：
   ```
   npm install
   ```
3. 啟動App：
   ```
   npm start
   ```
   App會常駐在Mac選單列 / Windows工作列的Tray小圖示，點擊可開啟設定。

## 打包成安裝檔

```
npm run dist
```
會依照 `package.json` 裡的 `build` 設定，產生Mac的 `.dmg` 或Windows的安裝程式（需在對應平台上執行打包，或使用CI）。

## 已實作功能

- 每隔設定的分鐘數自動提醒，計算基準是「上次真正完成休息的時間」，跳過不會重新展延一個完整週期
- 鎖定畫面全螢幕覆蓋所有螢幕，倒數1-10分鐘（可調整）
- 提醒彈出前有20秒（可調整）的「跳過這一次」小視窗，逾時自動鎖定
- 鎖定畫面內建「緊急跳過」按鈕，需長按3秒才會解鎖，並記錄使用次數
- 可設定啟用時間區段（例如只在上班時段提醒）
- 鎖定期間輪播內建4張久坐醫學實證卡片，可在設定頁上傳圖片/文字檔加入輪播
- 開機自動啟動、音效提醒開關、今日統計（完成次數/跳過次數/緊急跳過次數）

## 已知注意事項

- 這是第一版可執行原型，建議先在自己電腦上用 `npm start` 實際測試流程，尤其是多螢幕環境下鎖定視窗是否都正常涵蓋
- 若鎖定視窗卡住無法關閉，可用Tray選單「結束程式」強制退出（僅開發除錯用，正式使用不應該常態發生）
